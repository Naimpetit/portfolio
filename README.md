# Portfolio BTS SIO — HTML/CSS

Portfolio statique prêt pour GitHub Pages.

## Technologies

- HTML5
- CSS3
- Aucun JavaScript
- Aucun backend
- Aucun framework

## Ajouter un nouveau projet

### 1. Copier le modèle

Copie :

`projets/_modele-projet.html`

vers :

`projets/mon-nouveau-projet.html`

Puis remplace le contenu entre les textes d'exemple.

### 2. Ajouter les images

Crée :

`assets/images/projets/mon-nouveau-projet/`

Puis place tes captures dedans.

### 3. Ajouter la carte dans `projets.html`

Copie une carte existante et modifie :

- le `href`
- l'image
- le nom
- la description
- les technologies
- les compétences

### 4. Ajouter la carte dans `competences.html`

Dans chaque compétence concernée, copie une carte existante et modifie les informations.

Un projet peut donc être affiché dans plusieurs compétences.

### 5. Ajouter le projet sur l'accueil (facultatif)

Tu peux aussi copier une carte dans la section « Quelques projets » de `index.html`.

## CV

Remplace :

`assets/cv/cv.pdf`

par ton vrai CV.

Le nom du fichier doit rester `cv.pdf`, sauf si tu modifies les deux liens présents dans `index.html`.

## Photo de profil

Ajoute ta photo ici :

`assets/images/profil/photo-profil.jpg`

Tu peux aussi changer le nom du fichier dans `index.html`.

## Déploiement GitHub Pages

1. Mets tout le contenu du dossier à la racine du repository.
2. Fais `git add .`
3. Fais `git commit -m "Ajout du portfolio"`
4. Fais `git push`
5. Dans GitHub : **Settings → Pages**
6. Choisis la branche contenant les fichiers du site et le dossier `/ (root)`.
7. Enregistre.

Le site ne nécessite aucun serveur.
